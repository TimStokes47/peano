Peano is an open-source framework for solvers on dynamically adaptive
Cartesian meshes, with a C++ core and a Python API on top. It is the basis of
ExaHyPE 2, MGHyPE, ExaParty and applications such as ExaGRyPE and ExaSeis.

Everything else (installation, Spack/Docker/Apptainer, tutorials, how to cite
Peano) lives in the
[documentation](https://hpcsoftware.pages.gitlab.lrz.de/Peano/), whose main
page is generated from [`documentation/home.dox`](documentation/home.dox).
Build it locally with `doxygen documentation/Doxyfile`.
